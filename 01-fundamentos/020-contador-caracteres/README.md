# 020 Contador de caracteres

Un programa que te pide un texto y te dice cuántos caracteres tiene. Los
espacios también cuentan. Además, te dice si tu texto cabe en un mensaje de 280
caracteres y cuántos te sobran o te faltan.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a medir la longitud de una cadena de texto y a usar ese
número para tomar decisiones. También vas a ver qué pasa con una cadena vacía,
cuando presionas Enter sin escribir nada.

Símbolos y sintaxis nuevos: la función `len()`, que devuelve cuántos
caracteres tiene una cadena, y la cadena vacía `""`.
