# 023 Tabla de multiplicar

Un programa que te pide un número y te muestra su tabla de multiplicar del 1
al 10.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a repetir un cálculo un número fijo de veces con el ciclo
`for`. Vas a ver que, cuando sabes cuántas vueltas quieres dar, `for` es más
sencillo que `while`, porque no tienes que llevar el contador a mano.

Símbolos y sintaxis nuevos: el ciclo `for` con la palabra `in`, y la función
`range()`. Ojo: `range(1, 11)` llega hasta 10, porque se detiene justo antes del
segundo número.
