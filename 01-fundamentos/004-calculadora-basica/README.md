# 004 Calculadora básica

Una calculadora que te pide dos números y una operación (suma, resta,
multiplicación o división) y te muestra el resultado. Si intentas dividir entre
cero o escribes una operación que no existe, te avisa en lugar de fallar.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a tomar decisiones en tu código con una estructura
condicional: según la operación que escribas, el programa hace un cálculo u
otro. También vas a revisar un caso especial antes de calcular, como la
división entre cero.

Símbolos y sintaxis nuevos: `if`, `elif` y `else`, los dos puntos `:` y la
sangría para marcar bloques, el operador de igualdad `==`, el operador de
desigualdad `!=` y los valores `True` y `False`.
