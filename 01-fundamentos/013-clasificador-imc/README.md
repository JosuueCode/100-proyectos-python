# 013 Clasificador de IMC

Un programa que te pide tu peso y tu altura, calcula tu índice de masa corporal
(IMC) y te dice en qué categoría quedas: bajo peso, peso normal, sobrepeso u
obesidad. Es solo una referencia y no sustituye una consulta médica.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a usar paréntesis para controlar el orden de una fórmula y
una cadena de `elif` para clasificar un valor por rangos. También vas a ver por
qué el orden de las condiciones importa.

No hay símbolos nuevos: vas a combinar lo que ya viste en los proyectos
anteriores. Más adelante, en el proyecto 019, vas a conocer el operador `**`
para elevar al cuadrado.
