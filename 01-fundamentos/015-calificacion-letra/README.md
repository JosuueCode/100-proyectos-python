# 015 Calificación con letra

Un programa que te pide una calificación de 0 a 100 y te dice a qué letra
equivale: A, B, C, D o F. Si escribes un número fuera de ese rango, te avisa.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a armar una cadena de `elif` con varias condiciones,
ordenadas de la más alta a la más baja, y a validar que un número esté dentro
de un rango antes de usarlo.

Símbolos y sintaxis nuevos: la comparación encadenada, como
`0 <= calificacion <= 100`, para revisar si un valor está entre dos límites.
