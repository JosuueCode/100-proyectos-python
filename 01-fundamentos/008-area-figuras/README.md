# 008 Área de figuras

Un programa con un menú para calcular el área de un cuadrado, un rectángulo, un
triángulo o un círculo. Eliges la figura, escribes sus medidas y te muestra el
área.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a armar un menú de opciones con una estructura condicional
y a pedir datos dentro de cada bloque, solo cuando hacen falta. También vas a
usar las fórmulas de área y una constante para el valor de pi.

No hay símbolos nuevos: vas a combinar lo que ya viste en los proyectos
anteriores.
