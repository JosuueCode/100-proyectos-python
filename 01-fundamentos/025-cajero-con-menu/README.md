# 025 Cajero con menú

Un cajero automático con un menú que se repite: puedes consultar tu saldo,
depositar y retirar cuantas veces quieras, hasta que elijas salir. No te deja
retirar más de lo que tienes ni depositar cantidades negativas o en cero. Al
salir, te muestra cuántas operaciones hiciste y tu saldo final.

Es la evolución del cajero del proyecto 009, que solo permitía un retiro, y
cierra la etapa de fundamentos.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a juntar lo que aprendiste en fundamentos: constantes,
validación de datos, condicionales anidados, un contador y un ciclo `while`
que mantiene el programa funcionando hasta que tú decides terminarlo.

No hay símbolos nuevos. Compara este código con el del 009 y fíjate cuánto
cambia un programa cuando puede repetirse.
