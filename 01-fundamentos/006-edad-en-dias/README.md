# 006 Edad en días

Un programa que te pide tu edad en años y te dice cuántos meses, semanas, días
y horas has vivido, de forma aproximada.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a hacer varios cálculos con multiplicación y a usar el
resultado de uno como dato del siguiente. También vas a guardar los valores
fijos del programa en constantes, para que el código se entienda mejor.

Símbolos y sintaxis nuevos: los nombres de constantes en MAYÚSCULAS, como
`DIAS_POR_ANIO`.
