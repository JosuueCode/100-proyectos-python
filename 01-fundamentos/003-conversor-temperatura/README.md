# 003 Conversor de temperatura

Un programa que te pide una temperatura en grados Celsius y la convierte a
Fahrenheit, y después te pide otra en Fahrenheit y la convierte a Celsius.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a convertir el texto que escribes en un número decimal con
`float()` para poder hacer cálculos con él. Vas a usar las fórmulas de
conversión de temperatura y a redondear el resultado con `round()`.

Símbolos y sintaxis nuevos: los operadores aritméticos `+`, `-`, `*` y `/`, los
paréntesis `( )` para agrupar una operación, el guion bajo `_` en los nombres de
variables y una función dentro de otra, como `float(input())`.
