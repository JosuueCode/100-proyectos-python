# 014 Verificador de login

Un programa que te pide un usuario y una contraseña y revisa si coinciden con
los datos guardados. Para entrar, usa el usuario `admin` y la contraseña
`python123`.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a comparar cadenas de texto con `==` y a exigir que dos
condiciones se cumplan a la vez con `and`. También vas a ver que la comparación
distingue mayúsculas de minúsculas.

No hay símbolos nuevos: vas a combinar lo que ya viste en los proyectos
anteriores. Ten en cuenta que guardar contraseñas en el código solo sirve para
practicar; un sistema real nunca lo hace así.
