# 012 Validador de triángulos

Un programa que te pide la medida de tres lados y te dice si con ellos se puede
formar un triángulo. Si se puede, también te dice si es equilátero, isósceles
o escaleno.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a combinar varias condiciones en una sola usando
operadores lógicos, y a guardar el resultado de una comparación en una
variable. También vas a aplicar la regla de la desigualdad del triángulo: cada
par de lados debe sumar más que el lado que queda.

Símbolos y sintaxis nuevos: los operadores lógicos `and` (todas las condiciones
deben cumplirse) y `or` (basta con que se cumpla una).
