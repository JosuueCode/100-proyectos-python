# 009 Cajero simple

Un programa que simula un cajero automático. Empiezas con un saldo de 5000, le
dices cuánto quieres retirar y te avisa si el monto no es válido o si no te
alcanza el saldo.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a validar un dato antes de usarlo y a actualizar el valor
de una variable a partir de su valor anterior, como cuando el saldo baja
después de un retiro.

Símbolos y sintaxis nuevos: los operadores de comparación `<=` (menor o igual
que) y `>=` (mayor o igual que).
