# 001 Hola mundo

Tu primer programa en Python. Muestra "Hola mundo" y te da la bienvenida a la
ruta de los 100 proyectos.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a usar la función `print()` para mostrar cadenas de texto
en pantalla y vas a ver que Python ejecuta el código de arriba hacia abajo, una
línea a la vez.

Símbolos y sintaxis nuevos: los paréntesis de `print()`, las comillas `" "`
para escribir texto, el `#` para comentarios y las comillas triples `"""` del
docstring.
