# 022 Cuenta regresiva

Un programa que te pide un número y cuenta hacia atrás desde ese número hasta
cero, como el despegue de un cohete.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a usar un contador: una variable que cambia en cada vuelta
del ciclo `while` y que decide cuándo termina. También vas a ver por qué hay que
actualizarlo, porque si no cambia, el ciclo no se detiene nunca.

No hay símbolos nuevos: vas a combinar el `while` del proyecto anterior con la
actualización de variables que viste en el cajero del 009.

Si alguna vez tu programa se queda repitiendo algo sin parar, presiona
`Ctrl + C` en la terminal para detenerlo.
