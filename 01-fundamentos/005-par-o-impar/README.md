# 005 Par o impar

Un programa que te pide un número entero y te dice si es par o impar, y también
si es positivo, negativo o cero.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a leer números enteros con `int()` y a usar el residuo de
una división para saber si un número es par. También vas a usar dos
estructuras condicionales seguidas, cada una revisando algo distinto del mismo
número.

Símbolos y sintaxis nuevos: el operador módulo `%` y los operadores de
comparación `>` (mayor que) y `<` (menor que).
