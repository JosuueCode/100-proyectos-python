# 011 Mayor de tres números

Un programa que te pide tres números y te dice cuál es el mayor. Lo resuelve
solo con condicionales, comparando los números de dos en dos.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a usar condicionales anidados para comparar varios valores
paso a paso. También vas a asignar una variable en distintos bloques y usarla
después del condicional.

No hay símbolos nuevos: vas a combinar lo que ya viste en los proyectos
anteriores. Python tiene la función `max()`, que hace esto en una línea, pero
aquí la idea es que entiendas cómo se resuelve por dentro.
