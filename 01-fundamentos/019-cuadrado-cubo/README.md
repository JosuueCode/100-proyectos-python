# 019 Cuadrado y cubo de un número

Un programa que te pide un número y te muestra su cuadrado y su cubo. También
te enseña que el cuadrado da lo mismo si lo calculas multiplicando el número
por sí mismo.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a elevar un número a una potencia y a comparar el
resultado con la multiplicación repetida que usaste en proyectos anteriores,
como el del IMC.

Símbolos y sintaxis nuevos: el operador de potencia `**`. Por ejemplo,
`numero ** 2` es el cuadrado y `numero ** 3` es el cubo.
