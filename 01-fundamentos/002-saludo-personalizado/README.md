# 002 Saludo personalizado

Un programa que te pregunta tu nombre, tu ciudad y qué te gustaría crear con
Python, y te responde con un saludo hecho con tus datos.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a usar `input()` para pedir datos y guardarlos en
variables. También vas a mostrar texto junto con el valor de una variable
usando `print()` con varios valores.

Símbolos y sintaxis nuevos: el operador de asignación `=` y la coma `,` para
pasarle varios valores a `print()`.
