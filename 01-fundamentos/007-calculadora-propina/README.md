# 007 Calculadora de propina

Un programa que te pide el total de la cuenta y el porcentaje de propina que
quieres dejar, y te dice cuánto es la propina y cuánto vas a pagar en total.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a calcular un porcentaje con los operadores aritméticos y
a redondear cantidades de dinero a dos decimales con `round()`.

No hay símbolos nuevos: vas a combinar lo que ya viste en los proyectos
anteriores.
