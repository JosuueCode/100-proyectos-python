# 010 Conversor de monedas

Un programa que convierte una cantidad en pesos mexicanos a dólares, euros o
yenes. Las tasas de cambio están fijas en el código y son de ejemplo, así que
no las uses para cuentas reales.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a guardar las tasas de cambio en constantes y a usarlas
para convertir una cantidad según la opción que elijas. También vas a validar
la cantidad antes de revisar el menú.

No hay símbolos nuevos: vas a combinar lo que ya viste en los proyectos
anteriores. Si quieres practicar, cambia las tasas por las del día o agrega otra
moneda.
