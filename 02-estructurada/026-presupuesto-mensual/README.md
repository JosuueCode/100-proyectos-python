# 026 Presupuesto mensual

Un programa que te pide tu ingreso mensual y cuánto gastas en renta, comida,
transporte y otros gastos. Te muestra cuánto representa cada gasto, el total,
qué porcentaje de tu ingreso usas y cuánto te sobra o te falta.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

Con este proyecto empieza la etapa de programación estructurada. Vas a mostrar
texto y números juntos con f-strings, que son mucho más claros que las comas
de `print()` que usaste en fundamentos, y a dar formato a los números para que
siempre se vean con dos decimales, como el dinero.

Símbolos y sintaxis nuevos: los f-strings, como `f"Total: {total}"`, las llaves
`{}` para poner un valor dentro del texto y el formato de número `:.2f` para
mostrar dos decimales.
