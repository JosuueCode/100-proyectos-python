# 032 Piedra, papel o tijera

El juego de siempre contra la computadora. Eliges piedra, papel o tijera, la
computadora elige al azar y el programa te dice quién ganó la ronda. Lleva el
marcador de victorias, derrotas y empates, y puedes jugar las rondas que
quieras hasta que eliges salir.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a volver a usar `random`, ahora para que la computadora
elija un número del 1 al 3 que luego conviertes en una jugada con `if/elif`.
Más adelante, en el proyecto 038, vas a ver las listas, que hacen esta
conversión más corta. También vas a guardar condiciones en variables bool
para que las reglas del juego se lean con claridad.

No hay símbolos nuevos: todo lo que usa este proyecto ya lo viste antes.
