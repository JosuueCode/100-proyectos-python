# 039 Promedio de calificaciones

Un programa que te pregunta cuántas calificaciones vas a capturar, te las pide
una por una del 0 al 10 y las guarda en una lista. Al final te muestra el
promedio, la calificación más alta, la más baja y cuántas son aprobatorias,
es decir, de 6 o más.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a llenar una lista con un ciclo y a sacarle información
con funciones que Python ya trae. Lo que antes resolvías con acumuladores y
comparaciones, como sumar todo o buscar el mayor, ahora lo haces en una línea.
Para contar las aprobatorias sí recorres la lista con `for`, porque ahí tú
decides qué cuenta y qué no.

Símbolos y sintaxis nuevos: `sum()` para sumar los elementos de una lista, y
`max()` y `min()` para encontrar el valor más grande y el más pequeño.
