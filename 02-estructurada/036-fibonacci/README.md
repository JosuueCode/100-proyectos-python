# 036 Fibonacci

Un programa que te pide cuántos términos quieres ver y te muestra el inicio de
la sucesión de Fibonacci: 0, 1, 1, 2, 3, 5, 8, 13... Cada número es la suma de
los dos anteriores.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a escribir una función que repite un cálculo con `while`
y a avanzar dos variables a la vez con la asignación múltiple. Fíjate en que
la función no devuelve nada con `return`: su trabajo es mostrar los términos.

Prueba con 30 o 50 términos para ver qué tan rápido crecen los números.

Símbolos y sintaxis nuevos: la asignación múltiple, como `a, b = 0, 1` y
`a, b = b, a + b`, que da valor a varias variables en una sola línea.
