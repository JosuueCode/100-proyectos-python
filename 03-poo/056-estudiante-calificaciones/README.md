# 056 Estudiante y calificaciones

Un programa con un grupo de tres estudiantes. A cada uno le agrega sus
calificaciones, rechaza las que no van del 0 al 10, calcula su promedio y te
dice si aprueba con 6 o más. Al final te muestra quién tiene el mejor promedio.

## Cómo ejecutarlo

Desde esta carpeta:

```bash
python main.py
```

En Windows también puedes usar `py main.py`, y en macOS o Linux `python3 main.py`.

## Qué vas a practicar

En este proyecto vas a combinar objetos con listas de dos formas. Cada
estudiante tiene una lista como atributo para guardar sus calificaciones, y
el grupo completo es una lista de objetos que recorres con `for`.

Compáralo con el proyecto 039, donde calculabas el promedio de una sola lista
de calificaciones. Aquí cada estudiante lleva sus propios datos y sabe
calcular su promedio, así que manejar a uno o a cien es igual de sencillo.

No hay símbolos nuevos: vas a usar listas como atributos y listas de objetos
con lo que ya conoces.
